# inverteer

Minimal `caliss` contact page with `name`, `number`, and `email` fields in `index.html`.

To exercise submission locally, run `python server.py` from the repository root and open `http://127.0.0.1:8000/`.
When served from a web application, connect the `/contact` form target to a backend that accepts `POST /contact`.
The form submits the parameters `name`, `number`, and `email`.
You can also open the repository's local `index.html` file directly in a browser as a preview, but that mode is view-only and submission is intentionally disabled.
